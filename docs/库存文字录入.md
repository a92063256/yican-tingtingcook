# 库存文字录入

主厨在「库存 → 文字录入」粘贴或直接输入采购清单，页面即时整理，可修改名称、数量、单位、分类，移除不需要的项，再点击底部「确认入库」整批保存。

例如：

```text
芹菜一斤，酱油一瓶、猪肉罐头 2份。鸡蛋，10个。香菇
```

| 输入 | 记录结果 |
| --- | --- |
| 芹菜一斤 | 芹菜 1 斤，食材 |
| 酱油一瓶 | 酱油 1 瓶，调料 |
| 猪肉罐头 2份 | 猪肉罐头 2 份，食材 |
| 鸡蛋，10个 | 鸡蛋 10 个，食材 |
| 香菇 | 香菇 1 份，食材 |

## 支持的表达

- 多项用中英文逗号、顿号、句号、分号、斜杠、竖线、制表符、圆点或换行分开；名称与数量之间多出的逗号可自动关联。
- 中文数字、阿拉伯数字、全角数字、小数、半份量和“一斤半”；支持“半斤芹菜”“一斤半猪肉”等数量在前的写法。
- 支持编号或项目符号清单、数量括号和乘号，例如“1. 番茄（三个）”“五花肉×2份”；两侧均有完整名称、数量及单位时，空格也可分项。
- 单位包括份、克、千克、斤、两、个、瓶、罐、袋、包、盒、把、根、颗、粒、块、片、条、只、棵、捆、桶、毫升、升、勺。公斤/kg、公克/g、ml、l/公升会统一为千克、克、毫升、升；市斤、市两、枚及常用繁体单位可归一化，俩／仨可作为数量。
- 文字录入未写数量默认 1 份，仅有数字但没写单位也按份记录；原「逐项添加」继续允许数量留空，表示待确认。
- 调料字典预选分类，包括酱油、生抽、食盐、调味酱、食用油、香辛料等，保存前可自行调整。已有同名同单位库存时，沿用其分类。

不依赖 AI、外部 API 或网络服务。规则、单位与分类词表集中在 `src/stock-text.ts`，界面与解析逻辑独立，可继续扩充。

## 保存与匹配规则

文字录入表示新增采购。同一批次同名同单位先合并，再追加到已有数量，不覆盖旧库存。不同单位分别保留。已有数量待确认时，先补齐原库存数量后再追加；已有分类不同则提示统一分类。

主厨权限、字段范围、版本冲突在服务器再次检查；整批在同一 SQLite 事务内保存，任意一项失败都不写入。重复请求使用同一请求编号，断线后重试不重复累加。响应丢失时保留原批次并冻结修改，点击「重试并确认」核实结果，避免把重试变成另一笔采购；不要刷新或关闭页面后直接重新输入相同采购。

备菜可将 1 斤按 500 克、1 两按 50 克匹配；份、瓶、袋等包装数量不推算克数或容量。配方所需单位与库存不同且无法换算时，仍需核实数量。

不会根据类别推断保质期或用完日期，也不会因为做完一餐、勾选备齐而扣减库存。只有用户明确修改数量或点击「用完了」才改变这些数量状态。本功能不新增保质期字段或到期提醒。

## 解析边界

每批最多 100 项、10000 字；数量范围 0.0001 至 10000000，记录至小数点后四位。支持常见“名称 + 数量 + 单位”，不宣称理解任意自然语言。

“两到三斤”“适量”“保质期七天”“用完了”、多项之间未分隔、未知计量单位等表达会提示修改，存在未解析片段时不会只保存部分结果。名称可不在词表中，分类无法判断时先按食材，可在预览中纠正。原文一旦修改，解析预览会重新生成，请在文字整理完后再修正预览。

## 验证

新增解析和库存事务测试，覆盖混合标点、中文数字、斤/两歧义、默认份、调料分类、范围与模糊输入拒绝、备菜换算、权限、整批回滚、并发冲突、持久化和重复请求。各次验证结果见 [变更说明](../CHANGELOG.md)，当前可运行 `npm test` 与 `npm run build` 复核。

独立测试库、仅 `127.0.0.1` 的浏览器验证覆盖 320 / 360 / 390 / 1440 像素布局、预览修正与移除、重复项累加、刷新持久化、模糊文本阻止保存、逐项添加份单位，以及“服务端已提交但响应丢失”后的重试；已查看窄屏与桌面截图，无浏览器运行错误。

未验证真实手机软键盘和实际 Wi-Fi，自动浏览器不能替代实机。最小手动检查：在手机上打开「文字录入」，输入上面的示例，检查键盘弹出后能滚动到结果、收起键盘后能点击底部确认；应得到五项正确库存，再次输入酱油一瓶应只累加一瓶。实机联网验证另行安排，开发调试继续仅限本机。
